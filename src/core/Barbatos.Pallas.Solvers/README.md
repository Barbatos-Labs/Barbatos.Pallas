# Barbatos.Pallas.Solvers

Equation solving for Barbatos.Pallas: simultaneous linear equations, polynomials of degree 2 to 4 with exact surd roots for quadratics, a Newton solver and polynomial inequalities.

> **Status: preview, not yet implemented.** This package is scaffolded; its implementation lands in
> Phase 4 of the roadmap in [docs/ARCHITECTURE.md](https://github.com/Barbatos-Labs/Barbatos.Pallas/blob/main/docs/ARCHITECTURE.md).
> Do not take a dependency on it yet.

Part of [Barbatos.Pallas](https://github.com/Barbatos-Labs/Barbatos.Pallas), a precise scientific calculation
engine for .NET 8, 9 and 10 built on decimal, double and BigInteger. The precision guarantees every package upholds are
described in [docs/PRECISION.md](https://github.com/Barbatos-Labs/Barbatos.Pallas/blob/main/docs/PRECISION.md).

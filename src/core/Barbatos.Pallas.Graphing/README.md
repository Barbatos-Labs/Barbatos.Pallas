# Barbatos.Pallas.Graphing

Platform-neutral function graphing for Barbatos.Pallas: adaptive sampling, asymptote detection, and roots, extrema and intersections.

> **Status: not yet implemented.** This library is scaffolded; its implementation lands in Phase 6 of the roadmap in
> [docs/ARCHITECTURE.md](https://github.com/Barbatos-Labs/Barbatos.Pallas/blob/main/docs/ARCHITECTURE.md). Until then it has no
> code and ships in no package.

Part of [Barbatos.Pallas](https://github.com/Barbatos-Labs/Barbatos.Pallas), a precise scientific calculation
engine for .NET 8, 9 and 10 built on decimal, double and BigInteger. The precision guarantees every library upholds are
described in [docs/PRECISION.md](https://github.com/Barbatos-Labs/Barbatos.Pallas/blob/main/docs/PRECISION.md).
